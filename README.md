# Tharaasree Bill Manager downloads

Signed client APKs and update information for Tharaasree Bill Manager.

| App | Use |
| --- | --- |
| Tharaasree Dev | Client testing, using the Dev Drive workspace |
| Tharaasree | Regular billing, using the production Drive workspace |

Both apps can stay installed on the same phone and update independently.

## Download

Open [Releases](https://github.com/Dharaneesh-23/mobile-billing-application-download/releases)
and choose the installer supplied by the project owner. If no APK is listed, the first
signed client release has not been published yet. Debug builds are local development builds.

After the first installation, use the app menu's **Check for updates**. The app also
checks periodically. Android asks you to confirm installation of an update.

Application source is in a separate private repository. This public repository holds
client installers, release notes and update metadata. Customer bills and Drive data
are not published here.
